# GTM 单任务专注台（Focus Desk）

> 仓库 `flow-us` 是本项目的代码仓库，主文件 `focus-desk.html`。

一个强制「一次只专注一个任务」的个人工作台，为海外广告投放（GTM）场景定制。

- **在线地址**：https://workbuddy.link/p/6pAr2iqMMEXLKJUO45MeVg
- **形态**：单文件 HTML，全内联零依赖，数据存 WorkBuddy 资料库（多设备同步）

## 核心机制

主区域只展示当前选中的**唯一任务**，其余任务全部折叠进任务池。软提醒模式——想切换随时可以，但视觉和交互始终把你拉回「只盯这一个」。

## 功能模块

| 模块 | 说明 |
|---|---|
| 今天要处理（置顶） | 自动聚合逾期 / 今天到期 / 今日标记的任务。逾期红色标注 + 显示逾期天数，一键「专注」或「完成」。昨天没做完的自动滚到今天，不会消失 |
| 当前专注（主区） | 唯一任务卡片 + 番茄钟（15/25/45 分钟）+ 今日进展记录 |
| 任务池（双维度筛选） | 第一维「场景」：投放执行 / 数据分析诊断 / 周报汇报 / 对外沟通 / 个人项目<br>第二维「业务线」：mearsun / Garvee / Antom / OKX / 日韩市场 / Readdy / 个人项目 / 其他 |
| 本周概览 | 完成数 / 专注分钟 / 待办剩余 / 逾期项 四个指标卡 + 场景专注时长分布 |
| 专注热力图 | 近 15 周专注分钟热力图（4 档色阶），鼠标悬停看每周数值，下方汇总活跃周数与本周环比 |
| WoW 环比 | 按业务线录入周费用 / Leads，自动算 CPL 和三项环比（红涨绿跌）。自动预警：费用涨超 15% 但 Leads 未同步增长、Leads 归零 |
| 周报导出 | 一键生成结构化周报（整体判断 / 已完成 / 进行中 / 时间投入 / 业务线 WoW / 下一步计划） |

## 数据表结构

数据存 WorkBuddy 资料库，三张表：

| 表 | 字段 |
|---|---|
| 任务表 | 任务 / 场景 / 状态 / 优先级 / 截止日期 / 今日处理 / 业务线 / 备注 |
| 专注记录表 | 日期 / 任务 / 场景 / 专注分钟 / 备注 |
| 周数据表 | 业务线 / 周起始日 / 费用 / Leads / 备注 |

## 技术要点

- 单文件 HTML，CSS/JS 全内联，**零外部依赖**（无 CDN / 框架 / 图表库）
- 图标与图表全部手写内联 SVG
- 接 `__SMART_PAGE__.database` SDK，`databaseId` 硬编码，分页拉全量（`pageSize=200` + `startCursor`）
- 云端失败自动降级 localStorage，顶部提示离线模式，恢复后自动同步
- 渲染层严格遵守单向调用链：`renderToday / renderFocus / renderLines / renderPool / renderStats / renderHeat / renderWow / renderPm` 互不调用，统一由 `refreshAll()` 调度

## 本地使用

直接双击 `focus-desk.html` 用浏览器打开即可（离线模式，数据存 localStorage）。
需要多设备同步请用上方的在线地址。

## 注意事项

- 在线页面为公网可访问，拿到链接的人都能打开，建议不要填入敏感商业数据
- 仓库里的周数据示例（费用 / Leads）是虚构数字，实际使用请替换
